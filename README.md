# HackLatCom 🚀

La plataforma de hackathons en América Latina. Donde las ideas se transforman en proyectos reales.

## 🌟 Sobre HackLatCom

HackLatCom conecta desarrolladores, diseñadores, product builders y entusiastas tech de toda América Latina a través de hackathons épicos. Nuestra misión es construir una comunidad vibrante, inclusiva y colaborativa que impulse la innovación tecnológica en la región.

## 🎨 Características

- **Diseño Pixel Art/Cyberpunk**: Estética retro-futurista con colores neón vibrantes
- **100% en Español**: Contenido diseñado para la comunidad latinoamericana
- **Formulario de Registro**: Sistema completo para unirse a hackathons
- **Responsive**: Funciona perfectamente en móviles, tablets y desktop
- **Interactivo**: Animaciones sutiles, efectos glowing y experiencia inmersiva

## 🚀 Cómo Usar

1. Abre `index.html` en tu navegador
2. Explora las secciones de la landing page
3. Regístrate para el próximo hackathon

No requiere instalación ni dependencias. Es una página estática lista para usar.

## 🛠️ Tecnologías

- HTML5
- CSS3 (Custom animations, grid, flexbox)
- JavaScript vanilla (ES6+)
- Diseño responsive

## 💡 Secciones

1. **Hero**: Headline impactante con efecto glitch
2. **Propuesta de Valor**: Qué es HackLatCom
3. **Beneficios**: Por qué participar
4. **Registro**: Formulario funcional de inscripción
5. **CTA Final**: Llamado a la acción con estadísticas
6. **Footer**: Información y branding
