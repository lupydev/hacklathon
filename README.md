# HackLathon

Plataforma para comunidad de indie hackers y builders en LatAm

## 🚀 Sobre el Proyecto

HackLathon es una plataforma dedicada a organizar y promover hackathons en toda América Latina, enfocada en construir una comunidad tech fuerte e inclusiva. Conectamos developers, designers, product builders y entusiastas de la tecnología para participar en hackathons y ser parte de un movimiento regional.

## 🛠️ Tecnologías

- **Vite** - Build tool y dev server ultra rápido
- **TypeScript** - Type safety y mejor experiencia de desarrollo
- **CSS3** - Estilos modernos con variables CSS y animaciones

## 📋 Requisitos

- Node.js 18+ (se usó v20.19.6)
- npm 10+

## 🚀 Inicio Rápido

### Instalación

```bash
# Clonar el repositorio
git clone https://github.com/lupydev/hacklathon.git
cd hacklathon

# Instalar dependencias
npm install
```

### Desarrollo

```bash
# Iniciar servidor de desarrollo
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173) en tu navegador para ver el resultado.

### Construcción

```bash
# Compilar TypeScript y construir para producción
npm run build
```

Los archivos de producción se generarán en el directorio `dist/`.

### Vista Previa

```bash
# Ver la versión de producción localmente
npm run preview
```
